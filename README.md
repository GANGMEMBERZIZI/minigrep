# Minigrep

`minigrep` 是一个使用 Rust 编写的命令行搜索工具，模仿了经典工具 `grep` 的核心功能。本项目是基于《The Rust Programming Language》圣经教程实现的练习项目，旨在展示 Rust 在文件 I/O、模块化设计、错误处理以及生命周期管理等方面的特性。

## 功能特性

* **文本搜索**：在指定文件中搜索包含特定查询字符串的行。
* **大小写敏感控制**：
    * **默认模式**：执行区分大小写的精确搜索。
    * **忽略大小写模式**：支持不区分大小写的匹配逻辑。
* **灵活配置**：支持通过命令行参数传入查询词和文件路径，并通过环境变量控制搜索行为。
* **优雅的错误处理**：使用 `Result` 处理异常，并将错误信息输出至标准错误流 (`stderr`)，确保良好的用户体验。
* **内置测试**：包含针对核心搜索算法的单元测试。

## 安装与编译

在开始之前，请确保你已安装 [Rust 和 Cargo](https://www.rust-lang.org/)。

1.  克隆或下载本项目代码。
2.  进入项目根目录（包含 `Cargo.toml` 的目录）。
3.  使用 Cargo 进行编译：
    ```bash
    # 运行
    cargo run -- frog poem.txt
    
    ```
